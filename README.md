# AgriMart Microservices
Marketplace pertanian berbasis arsitektur microservices.

## TechStack
- NestJS
- Prisma ORM (v7)
- PostgreSQL
- REST API

## Struktur Project
```
agrimart-microservices/
├── api/              - semua microservices & gateway
├── cms/              - panel admin 
├── user/             - aplikasi user 
└── dokumentasi/      - dokumentasi 
```
